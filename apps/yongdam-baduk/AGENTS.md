# 용담바둑 유지보수 지침

## 제품과 표현

- 사용자에게는 쉬운 한국어와 존댓말로 안내합니다.
- 제품 이름은 `용담바둑`, 컴퓨터 상대 이름은 `용담`입니다. 화면, 알림, SGF, 설명서에서 이름을 일치시킵니다.
- PC와 휴대폰에서 읽기 쉬운 크기와 충분한 터치 영역을 유지합니다.
- 오프라인 컴퓨터 대국이 핵심 기능입니다. 필요한 화면, 스크립트, 모델, 아이콘, 설명서는 같은 사이트에서 제공하고 오프라인 캐시에 포함합니다.
- 난이도를 실제 검증된 급수·단수로 단정하지 않습니다. 탐색 횟수와 시간은 목표와 실측을 구분합니다.

## 버전과 사용 설명서 — 기능 변경 때마다 필수

1. 기능이 바뀔 때마다 `package.json`의 `version`을 올립니다. 기능 추가는 minor, 수정은 patch, 큰 호환성 변경은 major를 사용합니다. 같은 미배포 릴리스의 작업은 해당 릴리스에 함께 정리하되, 이미 배포된 버전 번호를 재사용하지 않습니다.
2. 버전의 기준은 `package.json` 하나로 유지합니다. 헤더의 제품명 바로 옆 버전, 앱 메타데이터, SGF의 앱 버전과 서비스 워커 캐시 버전을 같은 릴리스로 갱신합니다.
3. 헤더 오른쪽의 `사용 설명서` 링크를 항상 유지하고 `dist/manual.html`로 연결합니다.
4. 기능 변경과 함께 `dist/manual.html`의 실제 사용법, 보이는 버전, `meta[name="app-version"]`, 마지막 업데이트 날짜, 버전별 변경 내용을 수정합니다. `id="manual-version"`에는 `v`와 현재 버전을 표시합니다. 구현되지 않은 기능을 설명서에 약속하지 않습니다.
5. 새로운 파일이나 모델을 추가·변경하면 서비스 워커의 필수 캐시 목록을 갱신합니다. 준비 완료는 모든 필수 파일이 실제로 저장된 뒤에만 표시합니다.
6. 제품 이름, 주요 기능, 대표 문구나 시각적 정체성이 바뀌면 OG 이미지, 공유 메타데이터와 파비콘도 함께 검토하고 필요한 부분을 갱신합니다.

## 빌드와 확인

- `node scripts/build-shell.mjs`로 버전 표시와 앱 셸을 반영하고 `node scripts/check-release.mjs`로 헤더·설명서·캐시·메타데이터의 릴리스 일치 여부를 확인합니다.
- 신경망 코드나 번들 입력이 바뀌면 `npm run build:neural`을 실행합니다.
- `npm test`와 변경 범위에 필요한 규칙·엔진·오프라인 검사를 실행합니다. 실패한 상태로 완료를 선언하지 않습니다.
- 새 버전에서 대국 시작, 착수와 컴퓨터 응수, 무르기, 기보 저장·복기, 계가와 SGF 내보내기를 필요한 범위에서 확인합니다.
- 화면을 바꾸면 데스크톱과 작은 휴대폰 폭에서 가독성, 메뉴 접근, 잘림·가로 넘침을 확인합니다. 설명서는 실제 버튼 이름과 동작을 기준으로 점검합니다.
- 오프라인 관련 변경은 최초 준비 성공·실패 표시, 필수 파일 완전성, 연결을 끊은 뒤 화면과 엔진 실행을 검증합니다. 단위 테스트와 실제 브라우저 검증을 구분해서 보고합니다.
- 실제 실행하지 못한 검사나 확인하지 못한 기력은 검증 완료로 표현하지 않습니다.

## 배포와 데이터

- `.openai/hosting.json`의 기존 `project_id`를 유지합니다. 이 프로젝트를 갱신할 때 새 Site를 만들지 않습니다.
- 기존 Site 공개 범위와 접근 권한을 유지합니다. 배포를 위해 권한을 넓히지 않습니다.
- Sites의 정해진 소스 동기화·버전 저장·배포 흐름을 사용하고, 배포된 소스와 패키지의 커밋을 일치시킵니다.
- 사용자의 현재 대국과 최근 기보를 보존합니다. 저장 형식 변경에는 이전 기록을 읽을 방법이나 명시적인 마이그레이션이 필요합니다.
- 비밀 값과 인증 정보는 소스, 설명서, 테스트 출력에 기록하지 않습니다.

## 읽기 모드와 복기
- 큰 글씨를 기본으로 하며 ‘주니어’는 선택 사항입니다. 앱과 설명서에서 같은 기기의 선택을 유지합니다.
- AI 분석 수치와 승률은 추정값으로 표시하며 승률 기준 색상을 명시합니다. 복기와 연습은 원래 기보 및 진행 대국을 수정하지 않습니다.

## GitHub / Vercel 아카이브 배포
이 복사본의 운영 주소는 https://homong-app.com/용담바둑 입니다. homong-app-archive 저장소의 apps/yongdam-baduk을 루트로 사용하는 Vercel yongdam-baduk 프로젝트에 배포합니다. Sites 원본의 project_id는 이 복사본에 추가하지 않습니다. 원본 배포와 이 복사본 배포의 버전 및 주소를 구분합니다. 모델·이미지는 npm run build:archive로 복원하고 출처 및 SHA256 검증을 유지합니다.

헤더의 제품명 옆에는 최신 버전 번호를 표시합니다. 대국실 아래쪽에는 버전 번호와 엔진 출처 링크를 표시하지 않습니다. package.json·헤더·메타데이터·서비스 워커·설명서의 버전을 일치시킵니다. 새 대국 시작 버튼은 바둑판 위 도구 모음에 배치하며 플레이어 이름은 ‘나’로 표시합니다.
