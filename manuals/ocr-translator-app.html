📸 스크린샷 OCR 번역기
사용설명서

스크린샷이나 이미지의 글자를 OCR로 추출하고 선택한 언어로 번역합니다.

사용 순서

  1. 이미지 업로드 영역에서 스크린샷 파일을 선택합니다.
  2. OCR 인식 언어와 번역할 대상 언어를 선택합니다.
  3. OCR 추출 및 번역 시작을 누릅니다.
  4. 추출 텍스트와 번역 결과를 비교하고 필요한 내용을 복사합니다.
  5. 새 작업은 초기화를 눌러 이미지와 결과를 지운 후 시작합니다.

만들어지는 결과

이미지에서 추출된 원문 텍스트와 선택 언어의 번역 결과

사용 전 확인

  • 작거나 흐린 글자, 손글씨와 복잡한 배경은 오인식될 수 있습니다.
  • 개인정보가 포함된 이미지는 외부 번역 처리 가능성을 고려해 업로드하세요.
