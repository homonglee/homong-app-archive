🤖 Hermes Agent 소개 — Interactive One Page
사용설명서

Hermes Agent의 도구 실행, 멀티채널, 기억, 모델과 예약 작업 개념을 체험합니다.

사용 순서

  1. 상단 예시 작업 버튼을 눌러 에이전트 사용 사례를 살펴봅니다.
  2. 일반 AI와 Hermes 비교 탭으로 작업 방식 차이를 확인합니다.
  3. 목적 선택 영역에서 제공 모델과 워크플로우 구성을 탐색합니다.
  4. 예약 작업 시뮬레이터에서 할 일, 주기와 전달 채널을 선택합니다.
  5. Preview Output을 눌러 예상 결과를 보고 필요한 명령이나 내용을 복사합니다.

만들어지는 결과

Hermes 기능 설명, 일반 AI 비교, 예약 작업·도구 스택의 인터랙티브 미리보기

사용 전 확인

  • 소개 페이지의 시뮬레이션은 실제 Hermes 설치나 예약 작업을 자동 생성하지 않습니다.
  • 실제 기능과 설정 방법은 최신 Hermes 공식 문서를 기준으로 확인하세요.
