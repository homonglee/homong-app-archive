🧠 Memory Companion — 놓친 약속까지 기억하는 AI
사용설명서

대화 속 사람·프로젝트·할 일·날짜를 기억으로 구조화하고 실제 기록 검색과 미완료 약속 후속 확인을 체험합니다.

사용 순서

  1. 하단 입력창에 기억할 약속이나 할 일을 평소 말하듯 입력합니다.
  2. 자동 분류 결과에서 사람·프로젝트·날짜·중요도와 후속 확인 여부를 검토하고 필요하면 수정합니다.
  3. 기억에 저장을 눌러 열린 약속 목록에 추가합니다.
  4. 기억 검색에서 사람·프로젝트·행동 키워드 또는 자연어 질문으로 실제 기록을 찾습니다.
  5. 완료한 약속은 체크하고, Hermes에서 사용하려면 앱 카드의 Skill ZIP을 내려받아 스킬 폴더에 설치합니다.

만들어지는 결과

구조화된 기억 카드, 사람·프로젝트별 검색 결과, 미완료 약속 후속 확인 목록과 설치 가능한 Hermes 스킬 ZIP

사용 전 확인

  • 현재 공개 앱은 프런트엔드 프로토타입이라 새로고침하면 입력·수정한 데이터가 초기화됩니다.
  • 스킬을 실제 자동화에 연결할 때는 영구 저장소와 개인정보 보관 정책을 별도로 설정하세요.
