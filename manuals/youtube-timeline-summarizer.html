APP USER GUIDE · youtube-timeline-summarizer

▶️ 유튜브 타임라인 요약기
사용설명서

YouTube 영상 링크를 분석해 핵심 요약과 주제별 타임라인을 만들고 복사하거나 Markdown으로 저장합니다.

사용 순서

  1. YouTube 링크 입력란에 분석할 영상 주소를 붙여넣습니다.
  2. 3줄·5줄·회의록 중 원하는 요약 밀도를 선택합니다.
  3. 핵심성 기준과 관심 주제 필터를 필요에 맞게 조절합니다.
  4. 분석 실행을 누르고 영상 요약 결과와 타임라인이 나타날 때까지 기다립니다.
  5. 타임라인 검색으로 필요한 주제를 찾고 요약 복사 또는 MD 내보내기를 사용합니다.

만들어지는 결과

영상 핵심 요약, 주제별 타임스탬프·챕터, 복사용 텍스트와 Markdown 파일

사용 전 확인

  • 공개적으로 접근 가능한 정상적인 YouTube 영상 URL을 사용하세요.
  • 영상 길이와 자막 상태에 따라 분석 시간과 결과 품질이 달라질 수 있습니다.
