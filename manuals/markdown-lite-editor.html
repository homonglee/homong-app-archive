✍️ Live Markdown Studio
사용설명서

Markdown 파일을 불러오거나 문서를 작성하고, 원문 MD·HTML·PDF로 저장합니다.

사용 순서

  1. 파일 불러오기(Ctrl+O)로 .md·.markdown·.txt 파일을 선택하거나 직접 작성합니다. 현재 글이 있으면 덮어쓰기 확인이 표시됩니다.
  2. 제목·목록·표·링크 문법은 문법 도움말에서 확인합니다.
  3. 실시간 미리보기로 문서 모양을 점검합니다.
  4. 다크 모드와 미리보기 넓게로 작업 화면을 조절합니다.
  5. 파일명을 정하고 MD 저장(Ctrl+S)을 누르면 편집 가능한 원문이 저장됩니다. HTML·PDF 내보내기도 사용할 수 있습니다.

만들어지는 결과

Markdown 원문(.md), 실시간 미리보기, HTML 파일 또는 인쇄용 PDF

사용 전 확인

  • PDF 내보내기는 브라우저 인쇄 설정에 따라 여백과 줄바꿈이 달라질 수 있습니다.
  • 5MB 이하의 UTF-8·UTF-16 텍스트 파일을 지원합니다. 브라우저 자동 저장과 별도로 MD 저장을 눌러 원문 파일을 보관하세요.
