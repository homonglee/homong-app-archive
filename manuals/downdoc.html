🩺 DownDoc — 다운로드 폴더 클리닉
사용설명서

다운로드 폴더의 문서·이미지·설치 파일·중복 파일을 진단하고 정리 계획을 미리 봅니다.

사용 순서

  1. 정리할 폴더 경로를 입력합니다.
  2. 원하는 자동 분류 규칙을 켜거나 모두 켜기를 선택합니다.
  3. 폴더 스캔을 눌러 진단 리포트가 생성될 때까지 기다립니다.
  4. 분류·이름 표준화·중복 처리 등 정리 전후 계획을 검토합니다.
  5. 정리 적용하기를 누른 뒤 확인 창에서 안전하게 정리를 선택합니다.

만들어지는 결과

파일 유형·중복·이름 상태 진단과 정리 전후 미리보기

사용 전 확인

  • 웹 배포판은 사용자의 실제 PC 폴더를 직접 변경하지 않는 체험 모드일 수 있습니다.
  • 실제 파일 정리 전에는 중요한 파일을 백업하고 계획을 항목별로 확인하세요.
