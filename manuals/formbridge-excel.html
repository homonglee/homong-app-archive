APP USER GUIDE · formbridge-excel

📋 폼브릿지 — 신청서 엑셀 자동입력
사용설명서

신청서 PDF를 읽어 선택한 엑셀 시트에 입력하고, 여러 참고자료를 보관하며 기업 목록 연결·검수·저장·보고서 작성까지 이어서 처리합니다.

사용 순서

  1. 입력할 .xlsx 양식을 선택하고 스캔 정보를 입력할 시트를 고릅니다. 여러 시트 중 하나를 선택하며 다른 시트는 원본대로 보존됩니다.
  2. 소스 파일(예, 신청서, 동의서, 계약서) 영역에서 PDF·ZIP 선택 또는 폴더 선택으로 읽을 PDF를 추가합니다. ZIP과 하위 폴더 안의 PDF를 합산해 최대 3,000개를 등록할 수 있습니다.
  3. 파일 목록 읽기·폴더 탐색부터 소스 파일 업로드 중과 회전 표시가 나타납니다. 바로 아래의 현재 파일·폴더 목록·ZIP 항목과 확인한 PDF 수를 보며 기다려주세요. 전체 수가 확정되기 전에는 전체 업로드 백분율을 표시하지 않습니다. 브라우저 보관 중에는 소스 파일 저장 중, 완료 후에는 추가한 PDF 수와 전체 수를 안내합니다. 추가 중지는 이번 선택의 추가를 모두 취소하고 기존 목록을 유지합니다.
  4. 참고 자료 추가에서 표와 업무 문서를 여러 개 선택합니다. XLSX·XLS·XLSM·XLSB·ODS·CSV·TSV는 기업 담당자 정보의 표 연결을 지원하며, DOC·DOCX·HWP·HWPX·PDF·TXT는 확인용 문서로 첨부합니다.
  5. 처음 추가한 참고자료 중 첫 번째 표는 자동 연결을 시도합니다. 추가한 다른 표를 사용할 때는 그 파일의 표 연결을 누릅니다. 한 번에 표 파일 1개만 자동 연결에 사용하며, 양식 연결 단계에서 해당 파일의 시트와 업체명·사업자번호·담당자 정보 열을 지정합니다.
  6. 연결 해제는 자동 연결만 해제하고 원본을 보관하며, 제외는 첨부를 삭제합니다. 각 파일의 원본 내려받기로 원본을 받을 수 있습니다. DOCX·HWPX·TXT는 본문 보기로 최대 200,000자의 텍스트를 미리 봅니다. DOC·HWP·PDF는 원본을 내려받아 해당 프로그램에서 확인합니다.
  7. 양식 연결하기를 누르고 신청자 항목별 입력 열·셀과 표형 또는 고정 셀 배치를 확인합니다. 정보 추출 시작을 누르면 신청서의 스캔 페이지를 한국어·영어 OCR로 인식하므로 탭을 열어 둡니다.
  8. 작업 모니터에서 작업 시작 시각(KST), 작업 경과시간(HH:MM:SS), 전체 진행률(파일 기준), 예상 완료 시각 (KST)·예상 남은 시간과 현재 파일·쪽 상태를 확인합니다. 경과시간은 추출 실행 중에만 누적되며, 중지·탭 종료·저장 파일을 불러오기 전후의 대기시간은 제외합니다. 재시도해도 최초 시작 시각을 유지하고 경과시간은 이어서 누적합니다.
  9. 예상 시간은 이번 실행에서 PDF 2개 이상을 정상 완료한 뒤 최근 최대 5개 파일의 평균 소요시간과 현재 파일의 실제 완료 페이지·경과시간으로 계산합니다. 정상 완료 파일 표본이 부족해도 남은 파일이 1개라면 그 파일을 2쪽 이상 처리한 뒤 완료 페이지의 처리 속도로 추정합니다. 표본을 모으는 동안에는 계산 중을 표시합니다. 중복 제외 파일은 남은 개수에서 빼지만 평균 표본에는 넣지 않습니다. 중지하면 예상값을 숨기고 이어하기에서 새 실행의 파일·페이지 표본으로 다시 계산하므로 중지·앱을 닫아 둔 시간은 포함하지 않습니다.
  10. 추출을 멈추려면 중지·저장 후 나가기를 누릅니다. 완료한 파일·설정·수정값·누적시간을 이 브라우저에 저장한 뒤 작업 내역으로 이동합니다. 다음에는 작업 내역의 이어하기를 눌러 미완료 PDF부터 자동 재개합니다. 완료한 파일과 유효한 중복 제외 파일은 유지하지만, 멈춘 파일은 첫 페이지부터 다시 읽습니다.
  11. 근거 보기로 원본과 추출값을 비교하고 누락·충돌 항목을 해결한 뒤 검수 완료를 기록합니다. 상단 엑셀 결과 만들기로 결과를 생성하고 엑셀 내려받기(고정 셀은 ZIP 내려받기)를 눌러 브라우저 다운로드 목록에서 저장 완료를 확인합니다. 작업 저장은 브라우저 내역 보관이며 엑셀 다운로드가 아닙니다. 다시 연 작업의 결과는 재생성합니다.
  12. 이전 결과는 저장한 추출문 다시 분석으로 OCR 없이 신청인 구분·항목 연결을 갱신합니다. 직접 수정·확정한 값이나 수동 신청자가 있는 파일은 보존합니다. 보조 증빙은 신청자 행에서 제외하되 전체 소스 파일 · 보조 증빙 확인의 원본·추출문 보기로 확인하고 신청자 직접 추가를 할 수 있습니다. 신청인 구분 미확인 기록은 이 신청자 검토 완료 전까지 모든 연결 셀을 보류합니다.
  13. 참고자료만 첨부한 작업도 작업 저장과 백업 파일을 사용할 수 있습니다. 모든 참고자료 원본과 선택한 표, 연결 설정을 함께 보관·복원합니다. 다른 주소·기기로 옮길 때는 .formbridge 백업 파일을 내려받아 불러오기로 복원합니다. 시작 시각과 누적 경과시간도 저장되며, 강제 종료하면 최근 저장된 시간까지만 복원될 수 있습니다.

만들어지는 결과

선택한 시트에 입력한 XLSX 결과, 누락·충돌 검수 결과, 작업 보고서, 참고자료 원본과 작업 상태 전체를 복원하는 .formbridge 백업 파일

사용 전 확인

  • 입력할 출력 양식은 .xlsx 1개·25 MB입니다. 신청서 PDF는 최대 3,000개·총 30,000쪽이며 파일당 100 MB·500쪽까지 지원합니다. 참고자료는 별도로 최대 3,000개·파일당 25 MB이며 참고용 PDF도 25 MB 한도입니다. 처리 속도와 저장 용량은 기기 및 브라우저에 따라 달라집니다.
  • 참고자료에 첨부한 문서는 신청서 PDF 수량과 OCR 대상에 포함되지 않으며 기업 담당자 정보도 자동 연결하지 않습니다. 문서 속 기업 목록을 연결하려면 XLSX·CSV 표로 변환하고 표 연결을 사용하세요. 내용을 추출할 PDF는 소스 파일 영역에 추가합니다.
  • 본문 보기는 DOCX·HWPX·TXT 텍스트 최대 200,000자만 미리 보여줍니다. 서식·그림 재현이나 스캔 OCR 기능은 없으므로 전체 문서는 원본 내려받기로 확인하세요.
  • 업로드 중 추가 중지는 정보 추출의 중지·저장 후 나가기와 다릅니다. 이번 선택 전체가 취소되므로 파일을 추가하려면 다시 선택하세요.
  • 전체 진행률은 처리 완료와 중복 제외 파일 수를 전체 신청서 PDF 수로 나눈 값입니다. 실패·부분 완료는 포함하지 않아 추출이 끝나도 100%가 아닐 수 있습니다. 예상 완료 시각·남은 시간은 최근 파일 또는 마지막 파일의 페이지 기준 참고치입니다. 아직 페이지 수를 모르는 파일은 최근 평균으로 추정하며, 마지막 파일의 페이지 기준 예상은 남은 페이지의 문서 품질·재인식 횟수에 따라 달라집니다. 실패·부분 완료가 발생하면 재시도 필요로 표시하고 예상 완료 시각을 숨깁니다. 모든 파일이 정상 완료 또는 유효한 중복 제외로 처리되면 처리 완료와 남은 시간 00:00:00을 표시합니다.
  • 로컬 인식 설정에서 문서 종류·품질을 판단하는 자동 재인식과 기존 꼼꼼한 기준을 선택합니다. 자동 동시 인식은 최대 2개이며 1~4개 선택은 기기 조건에 따라 제한합니다. 3·4개는 실제 문서로 속도·안정성을 비교하는 시험 설정입니다. 지정 영역은 미리보기에서 드래그하거나 비율을 입력해 모든 소스 페이지에 적용하며 같은 배치의 서류에만 사용합니다. 항목이 부족하면 전체 페이지도 읽지만 영역 밖 모든 항목 복원을 보장하지 않습니다.
  • 중지·저장 후 나가기는 자동 저장을 꺼둔 작업도 저장을 켜서 보관합니다. 저장 실패 시 현재 화면에 남아 오류를 안내하므로 창을 닫기 전에 백업 파일을 내려받으세요. 이어하기는 쪽 단위 재개가 아니며, 이미 완료한 작업에는 표시되지 않습니다. 작업을 열어 검토하는 기능은 계속 사용할 수 있습니다.
  • 업데이트 전 작업의 과거 시작 시각은 알 수 없어 새 버전에서 다음 추출·재시작한 시점부터 기록합니다. 업로드 시각을 시작 시각으로 쓰지 않습니다. 이전 버전 탭이 추출 중이면 완료 전에 새로고침하지 말고, 완료 후 저장·백업한 뒤 새 버전을 적용하세요.
  • 파일과 작업은 현재 브라우저에 저장되며 다른 주소·기기와 자동으로 공유되지 않습니다. 아카이브 안에서 이전 작업이 보이지 않거나 저장에 문제가 있으면 앱 직접 열기를 사용하세요. 다른 주소로 옮길 때는 백업 파일과 불러오기를 사용합니다.
  • 작업 보관을 켠 정상 인식 결과 재사용은 이 브라우저에 유효기간 7일·32MB·500개(개별 2MB)까지 저장합니다. 만료 결과는 다음 앱 실행·저장 때 정리하며, 저장한 인식 결과 삭제 또는 전체 작업 삭제로 제거합니다. 수정값·참고자료 연결값은 재사용하지 않고 캐시는 백업에 포함되지 않습니다. 완료 파일에 새 설정을 적용하려면 전체 파일 다시 인식을 사용합니다. 재인식 버튼은 캐시를 건너뛰며 검수 상태와 수정값을 다시 확인해야 합니다.
  • 개인정보 동의서와 참여자 적격 확인서 묶음은 신청인·식별 정보 충돌을 확인해 파일 단위로 정리합니다. 안내문과 서명 잡음을 이름 값으로 자동 승인하지 않습니다. 구조화된 파일명의 이름·사업장은 파일명 참고 후보이며 본문 확인 후 확정해야 엑셀에 입력됩니다. 손글씨를 확실히 읽지 못하거나 문서에 실제 값이 없으면 자동 입력을 보류합니다. 서명일을 근무 시작일로 대체하지 않습니다. 이전 완료 파일은 저장한 추출문 다시 분석으로 구분·연결을 갱신하세요. 글자 자체가 잘못 읽혔으면 다시 인식하거나 직접 수정해야 합니다. 검토 항목 수는 실제 인원수가 아닙니다.
  • OCR 결과는 원본과 대조하세요. 보호된 입력 시트는 선택할 수 없고 수식 셀은 덮어쓰지 않습니다. 참고 표 지원 형식과 관계없이 결과를 쓰는 출력 양식은 XLSX만 지원합니다.
  • 소스 저장소는 비공개이며 이 아카이브에서는 실행 앱과 사용설명서를 제공합니다.

v1.6.2 인식·이전 결과 수정

  • 떨어져 읽힌 표의 머리글·값을 행과 열 위치로 연결하고 값 부분의 신뢰도를 확인합니다. 연결한 입력 항목 표시가 있는데 값을 못 찾으면 지정 영역을 사용하지 않는 페이지에 한해 최대 약 300dpi·긴 변 3,600픽셀로 한 번 더 확인합니다. 높은 해상도가 항상 더 좋지는 않으므로 더 나은 한 페이지 결과를 선택합니다.
  • 신청인·근로자 구간의 인쇄 이름 옆에 서명 잡음이 붙으면 이름 글자 영역만 작게 다시 읽습니다. 대표자·담당자 구간은 제외하며, 추가 인식도 이름 형식·신뢰도·파일명 불일치를 확인합니다. 손글씨와 흐린 스캔의 모든 항목 인식을 보장하지 않습니다.
  • 엑셀 결과 만들기에서 갱신 가능한 이전 분석이 있으면 저장된 추출문을 먼저 분석하고 내용 검토로 돌아갑니다. 검토한 뒤 결과 만들기를 다시 누르세요. 직접 수정·확정·수동 추가가 있는 파일은 자동 재분석에서 제외해 보존하므로 이 파일의 이전 구분·값은 원본과 대조해야 합니다.
  • 저장한 추출문 다시 분석은 새 OCR을 실행하지 않습니다. 새 인식 기준이 필요하면 작업·백업을 보관한 뒤 전체 파일 다시 인식 또는 해당 파일의 다시 인식을 실행하고 수정값·신청자 구분을 다시 검토하세요. 결과는 엑셀 결과 만들기 → 엑셀 내려받기로 저장합니다.

v1.7.0 암호 입력·추출 0건 검토

  • 암호가 있는 입력 XLSX와 참고 엑셀(XLSX·XLSM·XLSB·XLS)은 암호 입력 창을 표시합니다. 암호가 틀리면 다시 입력하고, 취소한 참고자료 원본은 첨부로 유지하여 표 연결로 다시 시도합니다. 지원하지 않는 암호 방식은 원본 프로그램에서 암호를 해제한 사본을 사용하세요. 시트 보호 해제 기능은 아닙니다.
  • 암호와 복호화한 원본은 브라우저 메모리에서만 사용하며 작업 저장·백업에 포함하지 않습니다. 다시 연 작업은 암호를 다시 입력합니다. 원본 내려받기는 암호를 유지하지만 생성하는 결과 XLSX에는 열기 암호가 없으므로 별도로 보호하여 보관하세요.
  • 100%는 파일 처리 완료를 뜻하며 추출 성공률이 아닙니다. 추출 내용이 0건이어도 내용 검토 화면으로 이동하여 원본·추출문 보기와 신청자 직접 추가를 사용하거나 저장한 추출문 다시 분석·전체 파일 다시 인식을 실행할 수 있습니다. 입력 대상이 없는 상태에서는 엑셀 결과를 만들지 않습니다.
  • 근로계약서에 보험 명부가 함께 붙은 파일은 계약서 전체를 보조 증빙으로 제외하지 않고, 보험 명부 페이지는 신청자로 추가하지 않습니다. 이전 작업은 저장한 추출문 다시 분석 후 원본과 대조하세요. 직접 수정·확정한 파일은 자동 재분석에서 보존합니다.

v1.8.0 필수 확인 일괄 선택

엑셀 양식 설정의 필수 확인 열에서 모두 체크로 현재 연결된 모든 항목을 필수로 지정하고 모두 해제로 일괄 해제합니다. 이후 개별 체크도 바꿀 수 있습니다. 설정은 작업 저장·백업 및 양식 저장에 포함되며 변경 후에는 검수를 다시 확인하세요. 추출값 확정이나 검수 완료 버튼과는 별개입니다.

v1.9.0 참고 기업 표 전체 열 확인

참고 기업 목록 연결의 미리보기를 N열까지만 표시하던 제한을 수정했습니다. 표 아래의 가로 스크롤로 A열부터 마지막 사용 열까지 이동하며 AA·AB 이후 열도 확인할 수 있습니다. 전체 열 수·마지막 열을 안내하고, 표에 초점을 둔 뒤 좌우 방향키로도 이동할 수 있습니다. 긴 값은 마우스를 올려 확인하세요. 미리보기는 처음 5~8행이며 표 연결에는 전체 기업 데이터가 사용됩니다.

v1.9.0 저장한 엑셀 양식 재사용

양식 연결에서 양식 저장을 누르면 엑셀 원본과 시트·행 범위·항목 연결·필수 확인·가림 출력·인식 설정을 이 브라우저에 함께 보관합니다. PDF 없이도 설정·저장할 수 있으며 PDF 추가 전에는 추출이 비활성화됩니다.

새 작업 화면의 저장한 양식 불러오기로 파일 선택 없이 불러옵니다. 현재 첨부한 PDF·참고자료는 유지합니다. 저장한 양식 목록의 새 작업에 사용은 엑셀과 설정만 넣은 별도 새 작업을 시작하고 소스 PDF·추출 결과를 복사하지 않습니다.

이전 설정만 있는 항목은 엑셀 원본 연결로 같은 파일을 한 번 연결하세요. 원본에 이미 있던 값은 포함되며 빈 양식을 권장합니다. 파일 열기 암호는 다시 입력합니다. 다른 주소·기기와 자동 공유하지 않으며 저장한 양식의 삭제는 해당 원본과 설정만 지웁니다. 전체 작업 삭제와는 별개입니다.
