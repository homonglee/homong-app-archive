▶️ 유튜브 타임라인 요약기
사용설명서

YouTube 자막 또는 직접 제공한 자막에서 문장을 발췌하고 타임라인·Markdown을 만듭니다.

사용 순서

  1. YouTube 링크 입력란에 분석할 영상 주소를 붙여넣습니다.
  2. 자동 자막이 차단되면 YouTube ‘스크립트 표시’의 자막을 붙여넣거나 SRT·VTT·TXT 파일을 불러옵니다. 입력 자막이 있으면 이를 우선 사용합니다.
  3. 3개·5개 발췌 또는 회의 메모 형식을 고르고 핵심어 빈도 기준과 주제 필터를 조절합니다.
  4. 분석 실행을 누르고 영상 요약 결과와 타임라인이 나타날 때까지 기다립니다.
  5. 타임라인 검색으로 필요한 주제를 찾고 요약 복사 또는 MD 내보내기를 사용합니다.

만들어지는 결과

자막 발췌 요약(검토용), 자막 시간에 따른 타임라인과 Markdown 파일

사용 전 확인

  • 공개적으로 접근 가능한 정상적인 YouTube 영상 URL을 사용하세요.
  • 현재 배포 서버의 자동 자막 요청은 YouTube에서 차단됩니다. 자막 직접 입력·파일 요약은 사용할 수 있습니다. 시간 없는 원문에는 타임스탬프를 만들지 않습니다.
