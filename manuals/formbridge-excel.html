📋 폼브릿지 — 신청서 엑셀 자동입력
사용설명서

신청서 PDF를 읽어 선택한 엑셀 시트에 입력하고, 여러 참고자료를 보관하며 기업 목록 연결·검수·저장·보고서 작성까지 이어서 처리합니다.

사용 순서

  1. 입력할 .xlsx 양식을 선택하고 스캔 정보를 입력할 시트를 고릅니다. 여러 시트 중 하나를 선택하며 다른 시트는 원본대로 보존됩니다.
  2. 소스 파일(예, 신청서, 동의서, 계약서) 영역에서 PDF·ZIP 선택 또는 폴더 선택으로 읽을 PDF를 추가합니다. ZIP과 하위 폴더 안의 PDF를 합산해 최대 3,000개를 등록할 수 있습니다.
  3. 파일 목록 읽기·폴더 탐색부터 소스 파일 업로드 중과 회전 표시가 나타납니다. 바로 아래의 현재 파일·폴더 목록·ZIP 항목과 확인한 PDF 수를 보며 기다려주세요. 전체 수가 확정되기 전에는 전체 업로드 백분율을 표시하지 않습니다. 브라우저 보관 중에는 소스 파일 저장 중, 완료 후에는 추가한 PDF 수와 전체 수를 안내합니다. 추가 중지는 이번 선택의 추가를 모두 취소하고 기존 목록을 유지합니다.
  4. 참고 자료 추가에서 표와 업무 문서를 여러 개 선택합니다. XLSX·XLS·XLSM·XLSB·ODS·CSV·TSV는 기업 담당자 정보의 표 연결을 지원하며, DOC·DOCX·HWP·HWPX·PDF·TXT는 확인용 문서로 첨부합니다.
  5. 처음 추가한 참고자료 중 첫 번째 표는 자동 연결을 시도합니다. 추가한 다른 표를 사용할 때는 그 파일의 표 연결을 누릅니다. 한 번에 표 파일 1개만 자동 연결에 사용하며, 양식 연결 단계에서 해당 파일의 시트와 업체명·사업자번호·담당자 정보 열을 지정합니다.
  6. 연결 해제는 자동 연결만 해제하고 원본을 보관하며, 제외는 첨부를 삭제합니다. 각 파일의 원본 내려받기로 원본을 받을 수 있습니다. DOCX·HWPX·TXT는 본문 보기로 최대 200,000자의 텍스트를 미리 봅니다. DOC·HWP·PDF는 원본을 내려받아 해당 프로그램에서 확인합니다.
  7. 양식 연결하기를 누르고 신청자 항목별 입력 열·셀과 표형 또는 고정 셀 배치를 확인합니다. 정보 추출 시작을 누르면 신청서의 스캔 페이지를 한국어·영어 OCR로 인식하므로 탭을 열어 둡니다.
  8. 작업 모니터에서 작업 시작 시각(KST), 작업 경과시간(HH:MM:SS), 전체 진행률(파일 기준)과 현재 파일·쪽 상태를 확인합니다. 경과시간은 추출 실행 중에만 누적되며, 중지·탭 종료·저장 파일을 불러오기 전후의 대기시간은 제외합니다. 재시도해도 최초 시작 시각을 유지하고 경과시간은 이어서 누적합니다.
  9. 추출을 멈추려면 중지·저장 후 나가기를 누릅니다. 완료한 파일·설정·수정값·누적시간을 이 브라우저에 저장한 뒤 작업 내역으로 이동합니다. 다음에는 작업 내역의 이어하기를 눌러 미완료 PDF부터 자동 재개합니다. 완료한 파일과 유효한 중복 제외 파일은 유지하지만, 멈춘 파일은 첫 페이지부터 다시 읽습니다.
  10. 근거 보기로 원본과 추출값을 비교하고 누락·충돌 항목을 해결한 뒤 검수 완료를 기록합니다. 결과 엑셀을 내려받고 작업 보고서를 생성합니다.
  11. 참고자료만 첨부한 작업도 작업 저장과 백업 파일을 사용할 수 있습니다. 모든 참고자료 원본과 선택한 표, 연결 설정을 함께 보관·복원합니다. 다른 주소·기기로 옮길 때는 .formbridge 백업 파일을 내려받아 불러오기로 복원합니다. 시작 시각과 누적 경과시간도 저장되며, 강제 종료하면 최근 저장된 시간까지만 복원될 수 있습니다.

만들어지는 결과

선택한 시트에 입력한 XLSX 결과, 누락·충돌 검수 결과, 작업 보고서, 참고자료 원본과 작업 상태 전체를 복원하는 .formbridge 백업 파일

사용 전 확인

  • 입력할 출력 양식은 .xlsx 1개·25 MB입니다. 신청서 PDF는 최대 3,000개·총 30,000쪽이며 파일당 100 MB·500쪽까지 지원합니다. 참고자료는 별도로 최대 3,000개·파일당 25 MB이며 참고용 PDF도 25 MB 한도입니다. 처리 속도와 저장 용량은 기기 및 브라우저에 따라 달라집니다.
  • 참고자료에 첨부한 문서는 신청서 PDF 수량과 OCR 대상에 포함되지 않으며 기업 담당자 정보도 자동 연결하지 않습니다. 문서 속 기업 목록을 연결하려면 XLSX·CSV 표로 변환하고 표 연결을 사용하세요. 내용을 추출할 PDF는 소스 파일 영역에 추가합니다.
  • 본문 보기는 DOCX·HWPX·TXT 텍스트 최대 200,000자만 미리 보여줍니다. 서식·그림 재현이나 스캔 OCR 기능은 없으므로 전체 문서는 원본 내려받기로 확인하세요.
  • 업로드 중 추가 중지는 정보 추출의 중지·저장 후 나가기와 다릅니다. 이번 선택 전체가 취소되므로 파일을 추가하려면 다시 선택하세요.
  • 전체 진행률은 처리 완료와 중복 제외 파일 수를 전체 신청서 PDF 수로 나눈 값입니다. 실패·부분 완료는 포함하지 않아 추출이 끝나도 100%가 아닐 수 있으며 남은 소요시간을 예측하는 값도 아닙니다.
  • 중지·저장 후 나가기는 자동 저장을 꺼둔 작업도 저장을 켜서 보관합니다. 저장 실패 시 현재 화면에 남아 오류를 안내하므로 창을 닫기 전에 백업 파일을 내려받으세요. 이어하기는 쪽 단위 재개가 아니며, 이미 완료한 작업에는 표시되지 않습니다. 작업을 열어 검토하는 기능은 계속 사용할 수 있습니다.
  • 업데이트 전 작업의 과거 시작 시각은 알 수 없어 새 버전에서 다음 추출·재시작한 시점부터 기록합니다. 업로드 시각을 시작 시각으로 쓰지 않습니다. 이전 버전 탭이 추출 중이면 완료 전에 새로고침하지 말고, 완료 후 저장·백업한 뒤 새 버전을 적용하세요.
  • 파일과 작업은 현재 브라우저에 저장되며 다른 주소·기기와 자동으로 공유되지 않습니다. 아카이브 안에서 이전 작업이 보이지 않거나 저장에 문제가 있으면 앱 직접 열기를 사용하세요. 다른 주소로 옮길 때는 백업 파일과 불러오기를 사용합니다.
  • OCR 결과는 원본과 대조하세요. 보호된 입력 시트는 선택할 수 없고 수식 셀은 덮어쓰지 않습니다. 참고 표 지원 형식과 관계없이 결과를 쓰는 출력 양식은 XLSX만 지원합니다.
  • 소스 저장소는 비공개이며 이 아카이브에서는 실행 앱과 사용설명서를 제공합니다.
