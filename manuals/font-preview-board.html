가 글자보기 — 무료 한글 폰트 비교 보드
사용설명서

무료 한글 폰트를 같은 문장으로 비교하고 크기·굵기·행간·자간을 조정합니다.

사용 순서

  1. 미리보기 문장을 직접 쓰거나 추천 문장을 선택합니다.
  2. 폰트 이름 검색으로 후보를 좁힙니다.
  3. 글자 크기, 행간, 자간과 Light·Regular·Bold 굵기를 조절합니다.
  4. 폭과 정렬 옵션을 바꾸며 여러 폰트 카드를 비교합니다.
  5. 마음에 드는 폰트를 찜하고 카드에서 제공하는 CSS 정보를 복사합니다.

만들어지는 결과

동일 문장의 폰트별 시각 비교, 즐겨찾기 목록과 적용용 CSS 정보

사용 전 확인

  • 실제 사용 전 각 폰트의 최신 라이선스와 허용 범위를 확인하세요.
  • 기기에 폰트가 로드되지 않으면 대체 글꼴로 보일 수 있습니다.
