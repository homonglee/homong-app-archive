💳 정기 구독 서비스 매니저
사용설명서

구독 서비스의 결제일·월 지출·활성·중지·해지 상태와 변경 이력을 관리합니다.

사용 순서

  1. 구독 추가를 눌러 서비스명, 카테고리, 금액과 다음 결제일을 입력합니다.
  2. 메모를 적고 대시보드에 추가합니다.
  3. 검색·상태 필터와 결제일·금액·이름 정렬로 구독을 찾습니다.
  4. 다가오는 결제와 6개월 지출 추이를 확인합니다.
  5. 사용하지 않는 구독은 중지·해지로 바꾸고 절약 추천을 참고합니다.

만들어지는 결과

월 구독 지출 요약, 결제 예정 목록, 상태별 구독 카드와 변경 타임라인

사용 전 확인

  • 앱의 상태 변경은 실제 서비스의 결제를 자동 해지하지 않습니다.
  • 결제 금액과 갱신일은 각 서비스 청구서에서 다시 확인하세요.
