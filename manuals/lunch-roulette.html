🍜 오늘 점심 뭐 먹지? 투표 룰렛
사용설명서

팀원 선호와 제외 메뉴, 주변 식당 후보를 반영해 점심 식당을 룰렛으로 결정합니다.

사용 순서

  1. 팀원 이름을 추가하고 각자 선호·제외 메뉴를 투표합니다.
  2. 내 주변 맛집 불러오기 또는 샘플 데이터로 후보를 준비합니다.
  3. 거리, 가격대와 정렬 기준으로 식당 후보를 좁힙니다.
  4. 필요하면 새 후보 식당의 이름과 메뉴를 직접 추가합니다.
  5. 룰렛 돌리기로 최종 식당을 정하고 결과 복사하기로 공유합니다.

만들어지는 결과

팀 선호도가 반영된 식당 후보와 룰렛 최종 선택 결과

사용 전 확인

  • 주변 식당 조회에는 브라우저 위치 권한과 OpenStreetMap API 연결이 필요합니다.
  • 룰렛은 적합도 가중치를 반영한 무작위 선택이므로 같은 조건에서도 결과가 달라질 수 있습니다.
