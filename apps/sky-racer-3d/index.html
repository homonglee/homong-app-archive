SKY RACER 3D 사용설명서

120초 안에 7개의 링을 순서대로 통과하세요.

휴대폰 · 터치 조작

Start를 누르면 자동으로 앞으로 비행합니다. 왼쪽의 상승·하강·좌선회·우선회 버튼을 길게 누르세요. 오른쪽 가속·감속 버튼을 동시에 누를 수 있습니다.

게임 화면을 손가락으로 누른 채 위·아래·좌·우로 드래그해도 조종할 수 있습니다. 손가락을 놓으면 조종이 중립으로 돌아갑니다. 가로 화면에서는 더 넓게 볼 수 있습니다.

마우스 · 키보드

마우스 드래그 또는 화면 버튼을 길게 눌러 조종합니다. W / S · ↑ / ↓ 상승·하강, A / D · ← / → 좌우 선회, Space 가속, Shift 감속, C 시점 전환, R 초기화.

시작 · 일시정지 · 초기화

Start → 일시정지 → 계속하기로 비행을 제어합니다. 초기화는 시간 120초, 점수 0점, 출발 위치로 돌아가 대기합니다. 사용설명서를 열거나 다른 앱으로 이동하면 비행은 일시정지됩니다. 닫은 후 계속하기를 눌러 주세요.

관찰 · 커스텀 · 게임 규칙

출발 전 화면을 드래그하면 드론을 360° 관찰할 수 있습니다. 커스텀 패널의 펼치기를 눌러 색상과 프로펠러 길이를 바꾸세요. 시점 버튼은 3인칭/조종석을, 배경 버튼은 낮/일몰을 전환합니다.

링 하나당 100점입니다. 충돌하면 출발 위치로 돌아가며 진행 점수와 남은 시간은 유지됩니다. 초기화해도 기체 꾸미기와 배경 선택은 유지됩니다.
