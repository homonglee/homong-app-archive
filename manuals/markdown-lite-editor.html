✍️ Live Markdown Studio
사용설명서

Markdown 문서를 작성하면서 웹 미리보기를 보고 HTML 또는 PDF로 내보냅니다.

사용 순서

  1. 빈 문서에 Markdown을 입력하거나 템플릿을 선택해 적용합니다.
  2. 제목·목록·표·링크 문법은 문법 도움말에서 확인합니다.
  3. 실시간 미리보기로 문서 모양을 점검합니다.
  4. 다크 모드와 미리보기 넓게로 작업 화면을 조절합니다.
  5. HTML 복사·HTML 내보내기 또는 PDF 내보내기를 사용합니다.

만들어지는 결과

실시간 렌더링된 문서, HTML 소스·파일 또는 인쇄용 PDF

사용 전 확인

  • PDF 내보내기는 브라우저 인쇄 설정에 따라 여백과 줄바꿈이 달라질 수 있습니다.
  • 초기화를 누르기 전에 필요한 원문을 별도로 저장하세요.
