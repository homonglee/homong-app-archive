🎙️ 보이스 메모 마인드맵
사용설명서

말하거나 입력한 아이디어에서 핵심어를 뽑아 마인드맵과 다음 행동으로 구조화합니다.

사용 순서

  1. 녹음 시작을 누르거나 아이디어를 텍스트로 직접 입력합니다.
  2. 말하기를 마친 뒤 정지를 누르고 변환된 텍스트를 확인합니다.
  3. 핵심어와 마인드맵 생성을 누릅니다.
  4. 방사형·클러스터·흐름 배치를 바꿔 관계를 살펴봅니다.
  5. 노드를 선택해 구조 인사이트와 다음 행동을 읽고 요약을 복사합니다.

만들어지는 결과

음성·입력 텍스트, 핵심어 마인드맵, 선택 노드 인사이트와 행동 제안

사용 전 확인

  • 마이크 권한을 허용해야 녹음 기능을 사용할 수 있습니다.
  • 음성 인식 오류가 있으면 텍스트를 수정한 뒤 다시 생성하세요.
