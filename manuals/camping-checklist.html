🏕️ Camping Checklist — 맞춤 캠핑 준비목록
사용설명서

캠핑 유형, 숙박 기간과 인원수에 맞는 준비물을 자동 추천받아 빠뜨림 없이 출발을 준비합니다.

사용 순서

  1. 백패킹·오토캠핑·차박캠핑·카라반·모터홈 중 이번 캠핑 유형을 선택합니다.
  2. 숙박 수와 함께 준비물을 사용할 전체 인원수를 설정합니다.
  3. 다음을 누르고 필요한 준비 카테고리를 켜거나 전체 선택을 사용합니다.
  4. 맞춤 체크리스트 만들기를 누르면 추천 품목이 모두 기본 선택된 상태로 생성됩니다.
  5. 필요 없는 물품의 체크를 해제하고, 품목을 눌러 수량·중요도·메모를 수정하거나 새 준비물을 추가합니다.
  6. 선택한 항목만 PDF 저장 또는 XLSX 저장으로 내려받고, 체크리스트 저장으로 현재 기기에 보관합니다.

만들어지는 결과

캠핑 유형·일정·인원에 맞춘 준비물 목록, 품목별 수량과 중요도, 선택 품목 수, 개인 메모 및 선택 항목 PDF·XLSX 파일

사용 전 확인

  • 저장 데이터는 현재 브라우저와 기기의 로컬 저장소에 보관되므로 다른 기기와 자동 동기화되지 않습니다.
  • 선택 품목까지 포함하면 목록이 크게 늘어날 수 있으므로 실제 캠핑장 시설과 반입 규정을 기준으로 조정하세요.
